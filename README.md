## Session 1: Introduction to Statistics in Data Science

### Overview of Completed Tasks

| Task | Topic | Key Deliverables |
|---|---|---|
| **Task 1** | App Data Classification | 5 real-world daily actions (Instagram, Zomato, Flipkart) classified into Categorical vs. Numerical data with scales of measurement. |
| **Task 2** | Music Genre Data Analysis | Classification of `['Pop', 'Rock', 'Jazz', ...]` as Nominal Categorical data with 3-line statistical reasoning and Mode computation. |
| **Task 3** | App Feature Enhancement | Improving Zomato's restaurant rating system using Bayesian Weighted Averages, Outlier Detection, and Time-Decay Weighting. |
| **Task 4** | Playlist Recommendation Analytics | Application of **Mode**, **Mean**, and **Variance** in a Spotify-like playlist recommendation algorithm with one-line examples. |
